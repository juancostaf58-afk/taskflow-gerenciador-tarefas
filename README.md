# TaskFlow — Gerenciador de Tarefas

Aplicação web para organização de tarefas, desenvolvida como projeto de estudo de desenvolvimento front-end.

## Funcionalidades

- Cadastro de tarefas
- Marcação de tarefas como concluídas
- Exclusão de tarefas
- Filtros por status
- Contadores de tarefas totais, pendentes e concluídas
- Persistência de dados com LocalStorage
- Interface responsiva para dispositivos móveis

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Como executar

1. Clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Adicione e gerencie suas tarefas.

## Aprendizados

O projeto permite praticar manipulação do DOM, eventos, arrays, funções, filtros, armazenamento local e organização de arquivos front-end.
